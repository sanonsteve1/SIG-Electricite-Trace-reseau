| **Type de règle**                             | **Objets concernés**                                                       | **Description détaillée**                                              | **Contraintes techniques**                                                                                   | **Exemples concrets (réseau électrique)**                  | **Bonnes pratiques (expert)**                                                  |
| --------------------------------------------- | -------------------------------------------------------------------------- | ---------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------- | ------------------------------------------------------------------------------ |
| **Jonction ↔ Jonction**                       | Équipements ponctuels (transformateur, disjoncteur, interrupteur, fusible) | Permet la connexion directe entre deux équipements                     | - Doivent appartenir au même domaine réseau<br>- Compatibilité des types d’actifs<br>- Respect des terminaux | Disjoncteur ↔ Transformateur<br>Interrupteur ↔ Sectionneur | Toujours définir les **terminaux** (entrée/sortie) pour contrôler les flux     |
| **Jonction ↔ Ligne (Edge-Junction)**          | Ligne (câble) + équipement (poste, coffret, poteau)                        | Permet à une ligne de se connecter à un équipement                     | - Respect du niveau de tension<br>- Géométrie connectée (snap)<br>- Type autorisé dans UN                    | Ligne HTA → Transformateur<br>Ligne BT → Coffret abonné    | Éviter les connexions directes HTA → BT sans transformateur                    |
| **Ligne ↔ Ligne (via jonction)**              | Deux lignes (câbles) + jonction intermédiaire                              | Connexion indirecte entre deux lignes via un point (épissure, manchon) | - Jonction obligatoire<br>- Même type ou type compatible<br>- Respect des phases                             | Câble BT ↔ Manchon ↔ Câble BT                              | Toujours modéliser les jonctions (ne jamais connecter deux lignes directement) |
| **Règle de terminal**                         | Équipements multi-bornes (transformateur, disjoncteur)                     | Définit par quel terminal la connexion est faite                       | - Configuration des terminaux obligatoire<br>- Sens logique respecté                                         | Entrée HTA → Transfo → Sortie BT                           | Indispensable pour les analyses de flux (trace)                                |
| **Règle de direction**                        | Tous les objets connectés                                                  | Définit le sens du flux (énergie)                                      | - Source définie (poste, centrale)<br>- Flux cohérent                                                        | Centrale → Ligne HTB → Poste → BT                          | Toujours définir les **subnetwork controllers**                                |
| **Règle de tension**                          | Lignes et équipements                                                      | Empêche la connexion entre niveaux incompatibles                       | - HTB ≠ HTA ≠ BT<br>- Transformateur obligatoire                                                             | HTA → Transformateur → BT                                  | Créer des **domaines de tension stricts**                                      |
| **Règle de phase**                            | Lignes et charges                                                          | Assure la compatibilité monophasé / triphasé                           | - Phases cohérentes<br>- Pas de mélange incohérent                                                           | Ligne triphasée → Transfo → ligne monophasée               | Important pour calcul de charge                                                |
| **Règle de connectivité autorisée (UN Rule)** | Tous objets                                                                | Définit explicitement les connexions autorisées                        | - Configurée dans ArcGIS UN<br>- Basée sur Asset Group/Type                                                  | Câble HTA autorisé à se connecter à disjoncteur HTA        | Toujours documenter les règles métier                                          |
| **Règle de connectivité interdite**           | Tous objets                                                                | Empêche des connexions non logiques                                    | - Bloquée dans UN<br>- Génère erreur topo                                                                    | Câble BT → Ligne HTB ❌                                     | Très important pour la qualité des données                                     |
| **Règle de contiguïté géométrique**           | Lignes                                                                     | Assure que les lignes sont correctement jointes                        | - Pas de gap<br>- Pas de superposition incorrecte                                                            | Deux segments de câble alignés                             | Nettoyage topo régulier                                                        |
| **Règle de snap spatial**                     | Tous objets                                                                | Connexion basée sur la position géographique                           | - Tolérance définie<br>- Snap obligatoire                                                                    | Ligne touche exactement un poteau                          | Toujours utiliser snapping dans ArcGIS                                         |
| **Règle de sous-réseau (Subnetwork)**         | Ensemble du réseau                                                         | Assure que les éléments appartiennent à un même réseau logique         | - Subnetwork controller défini<br>- Cohérence topo                                                           | Réseau alimenté par un poste source                        | Utilisé pour les analyses réseau                                               |
| **Règle de continuité**                       | Lignes                                                                     | Empêche les lignes isolées                                             | - Doit être connecté à un réseau                                                                             | Câble non connecté ❌                                       | Vérifier avec les traces réseau                                                |
| **Règle de validité topologique**             | Tous objets                                                                | Vérifie la cohérence globale                                           | - Validation obligatoire<br>- Dirty Areas                                                                    | Erreurs détectées automatiquement                          | Toujours valider après modification                                            |
